# CreateFindingRequest

The CreateFindingRequest message.

This message contains a oneof named target. Only a single field of the following list may be set at a time:
  - identityUserTarget
  - appUserTarget
  - decoyTarget
  - appResourceTarget
  - connectorTarget
  - tenantTarget
