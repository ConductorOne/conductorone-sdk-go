# TenantAuthConfig

The TenantAuthConfig message.

This message contains a oneof named provider_config. Only a single field of the following list may be set at a time:
  - google
  - microsoft
  - okta
  - onelogin
  - jumpcloud
  - pingone
  - oidc
  - c1Local
