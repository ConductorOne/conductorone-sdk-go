# SearchAppEntitlementResourceBindingsRequest

The request message for searching app entitlement resource bindings, the grants of an
 entitlement to a non-user app resource such as a group. Search from either end: set
 app_entitlement_id to list the resources granted an entitlement, or set app_resource_type_id
 and app_resource_id to list the entitlements granted to a resource. Exactly one of the two
 must be provided.
