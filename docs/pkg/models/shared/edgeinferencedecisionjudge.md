# EdgeInferenceDecisionJudge

EdgeInferenceDecisionJudge configures a decision-model judge choosing between the stage's efficient and capable
 tiers.


## Fields

| Field                                                                                                                                                             | Type                                                                                                                                                              | Required                                                                                                                                                          | Description                                                                                                                                                       |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `CapableLabel`                                                                                                                                                    | `*string`                                                                                                                                                         | :heavy_minus_sign:                                                                                                                                                | Label of the capable candidate.                                                                                                                                   |
| `Cutoff`                                                                                                                                                          | `*float64`                                                                                                                                                        | :heavy_minus_sign:                                                                                                                                                | Cutoff in [0, 1]. The judge selects the capable label only when its score is strictly above the cutoff; a score<br/> equal to the cutoff stays on the efficient tier. |
| `EfficientLabel`                                                                                                                                                  | `*string`                                                                                                                                                         | :heavy_minus_sign:                                                                                                                                                | Label of the efficient candidate. Must differ from capable_label.                                                                                                 |
| `EvidenceJSON`                                                                                                                                                    | `*string`                                                                                                                                                         | :heavy_minus_sign:                                                                                                                                                | Evidence the decision model scores, as a JSON document of at most 16,384 bytes.                                                                                   |
| `InstructionsJSON`                                                                                                                                                | `*string`                                                                                                                                                         | :heavy_minus_sign:                                                                                                                                                | Optional instructions for the decision model, as a JSON document of at most 16,384 bytes.                                                                         |
