# DirectoryMergeRule

DirectoryMergeRule decides whether an account from a directory belongs to an existing user. It is
 either a built-in rule or a custom CEL rule.

This message contains a oneof named rule. Only a single field of the following list may be set at a time:
  - builtin
  - custom
