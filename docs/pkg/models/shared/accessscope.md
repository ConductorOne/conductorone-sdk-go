# AccessScope

AccessScope narrows a cohort to the users who hold a grant. It is combined
 with any ProfileFilters using AND logic, and is a complete cohort definition
 on its own.

This message contains a oneof named scope. Only a single field of the following list may be set at a time:
  - appId
  - entitlement
